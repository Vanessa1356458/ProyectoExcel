# Excel Basico
Una aplicación de escritorio ligera e intuitiva simulando las funciones esenciales de una hoja de cálculo, desarrollada como proyecto interactivo.

📋 Características Principales
Gestión de Archivos: Opciones básicas para crear un Nuevo libro, Abrir archivos existentes y Guardar tu progreso.

Edición y Manipulación: Menú desplegable de edición con funciones rápidas como Copiar, Pegar y Cortar rangos de celdas.

Inserción de Elementos: Capacidad de agregar nuevas Filas y Columnas dinámicamente según lo requiera el usuario.

Fórmulas y Funciones Matemáticas: Menú dedicado con operaciones integradas listas para usarse, incluyendo:

Suma
Resta
Multiplicar
Dividir
Promedio
Máximo
Mínimo
Contar
Barra de Estado Dinámica: Cálculo automático en tiempo real que muestra el Promedio, Recuento y Suma al seleccionar múltiples celdas con datos numéricos.
